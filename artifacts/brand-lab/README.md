# ProofRoom Brand Lab

This is a local review surface for comparing seven ProofRoom visual identities against one fixed
product story. It does not change the production application or its behavior.

## Review it locally

From the repository root:

```bash
python3 -m http.server 4175
```

Open `http://127.0.0.1:4175/artifacts/brand-lab/`.

Use the seven concept buttons to restyle the product preview. The copy and sample state stay the
same. Compare how quickly each concept communicates three things:

1. The browser agent researches and prepares work.
2. Evidence rules keep unknowns visible.
3. A person controls buyer context and the final decision.

The page is intentionally separate from the Vite application. A selected brand direction should be
approved before any production design tokens, components, or screenshots are changed.

## Mission Control source

Mission Control translates the Field Systems design language from
`/Users/treyharnden/Projects/TreyHarndencom-LinkTree`. It reuses the source repo's licensed Black
Ops One and IBM Plex Mono font files, near-black field surfaces, mint system signals, rust action
color, square geometry, and row-based information structure. It does not copy the personal site's
page layout, content, imagery, or identity mark.
