# Rejected Mutation: Visual Expansion

## Proposal

Expand ProofRoom with animated personalization transitions, five stakeholder briefs, three-plan comparison, a vendor response panel, multiple buyer personas, and an interactive evidence graph.

## Evaluation

The expansion would create more screenshot variety and a denser product impression. It would also weaken the canonical demo, add state and responsive-layout risk, increase the number of fixtures, and encourage shallow implementation across too many features.

## Decision

Reject. Keep one buyer, two stakeholder briefs, three surfaces, and nine tools. Put visual effort into one memorable transformation and a highly legible evidence trail rather than more modules.
